## Project permissions

| Permission | Allows | Lowest project role | API key scope |
|---|---|---|---|
| `read` | Read telemetry, MCP analytics, dashboards, alerts, saved queries | viewer | read |
| `ingest` | Send telemetry | none (keys only) | ingest |
| `write_facts` | Write tags, flags, comments, feedback, corrections | member | write |
| `edit_content` | Create and edit dashboards, saved queries, alert rules | member | none (keys never) |
| `run_sql` | Run ad hoc SQL | member | sql |
| `export` | Create exports | member | read |
| `run_saved_query` | Run a project-visible saved query (declared parameters only) | viewer | sql |
| `channels` | Channels (they hold secrets), test-send | admin | none (keys never) |
| `manage` | API keys, project settings, retention, model prices, project members | admin | none (keys never) |
| `delete_traces` | Delete traces | member | delete |
| `delete_by_user` | Delete by user or session | admin | delete |

## Org permissions

| Permission | Allows | Lowest org role |
|---|---|---|
| `org_read` | Read the organization; list members and invitations | viewer |
| `org_settings` | Org settings, sign-in providers, password-login switch | admin |
| `org_members` | Change members and invitations (an admin cannot change or make owners) | admin |
| `org_projects` | Create or delete projects | admin |
| `org_transfer_ownership` | Transfer ownership | owner |

Org owners and admins are project admins on every project. With `project_access = all` (the default) org members and viewers have their org role on every project; with `explicit`, only through a project membership. The effective project role is the higher of the two. API keys are project principals: they never manage keys, members or settings.
